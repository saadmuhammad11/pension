# AG Office Punjab — AI Pension Portal (Project Docs)

Working knowledge base for the AI-based pension portal for the Accountant General Office, Punjab.

## Contents

| Path | What it contains |
|---|---|
| `research/01-pension-calculation-pakistan-research.md` | How pension is calculated in Pakistani (esp. Punjab) government service: legal framework, kinds of pension, qualifying service, emoluments, gross/net pension, commutation, family pension, increases, 2024–26 reforms, implications for the system. Includes verification items. |
| `research/02-glossary-business-terms.md` | Domain glossary: institutions (AG, DAO, PSA, FD, NADRA…), documents (PPO, LPC, Annex-A, Forms B/D/C…), calculation and payment-cycle terms. |
| `source-document/00-document-overview.md` | Map of the 31-page uploaded scan: what the two documents inside it are and how they relate. |

| `source-document/02-fd-reformed-pension-procedure.md` | Punjab FD letter FD.SR-III/4-303/2012 (01-04-2014) + Reformed Pension Processing & Disbursement System: Rule 5.4 notes, step-by-step procedures per pension type, PPO issuance, life-certificate cycle, PFC, reconciliation, monitoring. |
| `source-document/03-forms-and-annexures.md` | The prescribed proformae: Annex-A, Forms B-I…B-IV, D-I, D-II, C (life certificate), C-1 (no-marriage certificate) — fields and notes. |
